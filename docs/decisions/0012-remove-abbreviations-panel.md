# 0012. Remove the abbreviations panel

**Status:** Accepted

## Context

The original program had a list of abbreviations, but its data isn't available. Both editions showed an empty panel promising the list "in a future version".

## Decision

Remove the panel from both editions, and remove its mentions from the guide and the README.

## Consequences

- The app no longer promises something it doesn't have.
- This is the one known difference from the original's features. If the data becomes available, the panel can return in a new version.
